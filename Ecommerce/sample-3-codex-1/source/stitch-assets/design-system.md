# Sông Hồng Core Design System

Source: Stitch project `Modern E-commerce UI` (`1994126963491177429`)

## Creative North Star
- The Kinetic Curator
- Editorial, asymmetric, premium e-commerce experience
- Use breathing room and tonal depth instead of dense boxed grids

## Core Colors
- Primary: `#b22204`
- Primary container: `#d63c1e`
- Secondary: `#165db2`
- Surface: `#f9f9f9`
- Surface low: `#f3f3f3`
- Surface lowest: `#ffffff`
- Text: `#1a1c1c`
- Outline variant: `#e3beb6`

## Rules
- No 1px hard borders for sectioning
- Use background color shifts to separate surfaces
- Use glassmorphism on floating nav and quick actions
- Prefer tonal layering over heavy shadows
- Use Vietnamese labels in the interface

## Typography
- Display/headlines: Be Vietnam Pro
- Body/labels: Inter
- Prices should use bold display styling

## Components
- Primary buttons: rounded XL, coral gradient, no border
- Filter chips: pill shape, neutral background when idle, secondary blue when active
- Inputs: soft filled surfaces, no boxed borders, ghost focus ring
- Product cards: large radius, white space separators, asymmetry in desktop layouts
- Flash sale tracker: gradient progress from primary to secondary with subtle pulse
