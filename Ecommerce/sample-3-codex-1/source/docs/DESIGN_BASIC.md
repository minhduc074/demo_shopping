# Sông Hồng Core - Basic Design

## Product Goal

Build a fashion-forward commerce demo that feels closer to an editorial magazine than a generic grid store while preserving core shopping flows.

## Core Screens

- Homepage: hero storytelling, featured products, discovery grid
- Product listing: browse the catalog with consistent branded cards
- Product detail: large imagery, descriptive copy, price emphasis, buy CTA
- Cart: selected items, quantity summary, order preview
- Checkout: shipping and payment handoff
- Account: personal snapshot and order-related context

## Primary User Journey

1. Land on the homepage and discover curated products.
2. Open a product page from the editorial grid.
3. Add the item to cart.
4. Review totals in cart.
5. Complete checkout through Stripe.

## Design Intent

- Coral action color for emphasis
- Soft tonal backgrounds instead of a plain white grid
- Larger product imagery and generous spacing
- Vietnamese copy mixed with modern commerce language
- Premium, less marketplace-like rhythm across pages
