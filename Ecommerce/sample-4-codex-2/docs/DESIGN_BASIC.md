# Stitch Commerce OS - Basic Design

## Product Goal

Demonstrate a richer commerce platform that goes beyond a single storefront page set and includes account and admin surfaces while staying faithful to the Stitch-generated visual language.

## Core Screens

- Login
- Register
- Homepage
- Search results
- Product detail
- Shopping cart
- Checkout
- Orders
- Admin dashboard
- Product management

## Primary User Journey

1. User lands on the homepage and browses seeded categories.
2. User searches or filters into the catalog.
3. User opens a product, adds it to cart, and proceeds to checkout.
4. After purchase, the user tracks orders in the orders page.
5. Admin users monitor health and inventory from dashboard pages.

## Design Intent

- Shopee-inspired coral accents with more editorial spacing
- Clear split between storefront and admin surfaces
- Database-backed catalog rather than placeholder cards
- Responsive rails and section grouping derived from Stitch mockups
